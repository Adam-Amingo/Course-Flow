# CourseFlow (KNUST Edition) 🎓

This is the source code for the CourseFlow academic management platform.

## 🛠️ How to Run on Your PC

To run this app, you need **Node.js** installed.

### 1. Install Requirements
This is a Javascript/Node.js project, so it uses `package.json` instead of a Python `requirements.txt`.
Download and install Node.js (LTS version) from: [nodejs.org](https://nodejs.org/)

### 2. Download the Code
- **Clone this repository** (or unzip the folder).
- Open your terminal (Command Prompt or PowerShell).
- Navigate to the project folder:
  ```bash
  cd courseflow
  ```

### 3. Install Dependencies
Run this command to download the necessary libraries (React, Tailwind, etc.):
```bash
npm install
```

### 4. Start the App
Run this command to launch the local server:
```bash
npm run dev
```

The app will open in your browser at `http://localhost:5173`.
